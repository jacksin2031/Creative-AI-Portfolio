# Creative AI Portfolio

## GitHub Pages で公開する手順

1. このZIPの中身を `jacksin2031/Creative-AI-Portfolio` の `main` ブランチ直下に上書きアップロードします。
2. GitHub の **Settings → Pages** を開きます。
3. **Build and deployment** の Source を **Deploy from a branch** にします。
4. Branch を **main**、Folder を **/(root)** にして Save。
5. 数分後、以下で公開されます。

`https://jacksin2031.github.io/Creative-AI-Portfolio/`
